Datenschutzerklärung

Anwendung: Cortex · Stand: Oktober 2026

1. Zweck der Anwendung

Cortex ist eine private, nicht-kommerzielle Anwendung zur persönlichen Organisation von Terminen und Aufgaben. Sie wird ausschließlich vom Entwickler selbst genutzt.

2. Welche Daten verarbeitet werden

Nach ausdrücklicher Freigabe durch den Nutzer greift Cortex über die offizielle Google-Calendar-API auf dessen Kalenderdaten zu. Dazu gehören Titel, Datum, Uhrzeit, Dauer, Ort und Beschreibung von Terminen.

3. Wo die Daten verarbeitet werden

Die Verarbeitung findet ausschließlich lokal auf dem Gerät des Nutzers statt. Es werden keine Kalenderdaten an Dritte übermittelt, nicht auf fremden Servern gespeichert und nicht zu Werbe- oder Analysezwecken verwendet. Es findet kein Verkauf von Daten statt.

4. Zugangsdaten

Der von Google ausgestellte Zugangstoken wird ausschließlich lokal auf dem Gerät des Nutzers gespeichert und dient allein der Authentifizierung gegenüber der Google-Calendar-API.

5. Weitergabe an Dritte

Es erfolgt keine Weitergabe von Daten an Dritte. Eine Ausnahme besteht nur, soweit eine gesetzliche Verpflichtung dazu besteht.

6. Zugriff widerrufen

Der erteilte Zugriff kann jederzeit unter myaccount.google.com/permissions widerrufen werden. Lokal gespeicherte Zugangstoken können durch Löschen der entsprechenden Datei auf dem Gerät entfernt werden.
